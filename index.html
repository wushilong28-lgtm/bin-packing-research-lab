EXPERIMENT SETUP

Design your experiment

01 / 03

Both models use the same true job sizes and arrival order. Change the settings and rerun the experiment.

01 Sampling

First Fit checks open bins from oldest to newest and uses the first bin with room.

True sizes are sampled independently: a ~ Uniform(0, 1)

02 Perceived & reported size

A job is first perceived as z = clip(a + ε, 0, 1), where a is its true size and ε is judgment error. The next section uses z to select a mode; that mode determines the final reported size.

Normal distribution: ε ~ N(0, σ²). Clip a + ε to [0, 1] to obtain z.

03 Mode selection probability

g(z) is the probability of choosing Hard mode for a job with perceived size z. Otherwise the job uses Simple mode. Mode selection never uses the true size directly.

Variable z ∈ [0, 1]. Supports +, −, ×, ÷, ^, parentheses, exp, log, sqrt, abs, min, max, clamp, and step.

04 Feedback

αⱼ = bⱼ × max(Xⱼ − s, 0) × c

Xⱼ is the perceived size z used for mode selection, after judgment error and clipping. s is the Simple upper bound. bⱼ = 1 for Simple and 0 for Hard.

Only Simple jobs with perceived size above s contribute feedback. Model 2 objective: bins + Σαⱼ. Turn feedback off to use bin count alone. Rerun to apply changes.

EXPERIMENT RULES

How to read this experiment

1

Each trial draws jobs with true sizes a between 0 and 1. Bins have capacity 1; a job opens a new bin if no eligible bin fits.

2

Judgment error gives perceived size z = clip(a + ε, 0, 1). Hard mode is chosen with probability g(z); otherwise the job uses Simple mode.

3

Simple reports min(tₛ, z), capped at tₛ. Hard reports max(tₗ, z), floored at tₗ.

4

First Fit checks bins in opening order and uses the first one with room. Both models use this same placement rule.

5

Model 1 packs true sizes; Model 2 packs reported sizes without checking true sizes. Compare their bin counts across paired trials.

6

Optional feedback uses perceived size Xⱼ = z: αⱼ = bⱼ × max(z − s, 0) × c. bⱼ is 1 for Simple and 0 for Hard. Add all jobs’ feedback to Model 2’s bin count; when feedback is off, αⱼ = 0.
