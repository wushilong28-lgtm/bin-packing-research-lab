EXPERIMENT SETUP

Design your experiment

01 / 03

One user, repeated submissions and optional quality feedback. Both packing models share the same true jobs; every trial starts with q = 0.

01 Sampling

First Fit checks open bins from oldest to newest and uses the first bin with room.

Requires 0 < s < 0.5 and h = 1 − s. With K > 0, Simple at r = s first fills an eligible existing ordinary Hard bin; only if none fits is it reserved, up to K bins. Arriving Hard at r = h first matches a reserved Simple; otherwise it enters ordinary FF/BF. Hard is never reserved. All reserved bins count; jobs never move after placement.

02 Data distribution

This generates true sizes a. Judgment error below changes the user's perception z separately. The single user draws every job from this distribution.

03 Perceived & reported size

A job is first perceived as z = clip(a + ε, 0, 1), where a is its true size and ε is judgment error. The next section uses z to select a mode; that mode determines the final reported size.

Normal distribution: ε ~ N(0, σ²). Clip a + ε to [0, 1] to obtain z.

04 User response

One user submits all jobs sequentially. Mode choices use the current perceived size and this user's past feedback.

g(z,t) = g₀(z) + λ·qₜ₋₁·(1 − g₀(z))

q starts at 0 in each trial. The user does not know the merchant's bounds s, h or the current reported size when choosing.

05 Mode selection

g₀(z) is the base probability of choosing Hard. With feedback on, past quality outcomes raise it using the formula above; otherwise use g₀(z) directly.

Variable z ∈ [0, 1]. Supports +, −, ×, ÷, ^, parentheses, exp, log, sqrt, abs, min, max, clamp, and step.

This curve shows the base g₀(z), equivalent to q = 0. The results show the adjusted probabilities over submissions. Mode selection never uses true size directly.

06 Feedback

On: update quality history after placement and adjust the next Hard probability. Off: use g₀(z), keep q = 0 and set α = 0. Rerun to apply changes.

q = failed Simple / observed Simple
αⱼ = c·max(zⱼ − rⱼ, 0)

After a Simple job, add one observation; a shortfall means the perceived need z exceeds the resource r assigned by the merchant. Successful Simple jobs also count. Hard leaves q unchanged. With no Simple observations, q = 0. No learning rate or initial-rate parameter is used.

For Simple, αⱼ = c·max(zⱼ − s, 0); for Hard, αⱼ = 0. Feedback uses perceived size after judgment error, not true size. Model 2 objective: bins + Σαⱼ. History resets in every independent trial.

EXPERIMENT RULES

How to read this experiment

1

Each trial draws jobs with true sizes a between 0 and 1. Bins have capacity 1; a job opens a new bin if no eligible bin fits.

2

Judgment error gives perceived size z = clip(a + ε, 0, 1). One user draws Hard with probability g₀(z) + λq(1 − g₀(z)) when feedback is on, or g₀(z) when it is off. q contains only earlier Simple outcomes. The user does not know the merchant's s or h.

3

Simple reports min(tₛ, z), capped at tₛ. Hard reports max(tₗ, z), floored at tₗ.

4

First Fit checks bins in opening order and uses the first one with room. Both models use this same placement rule.

5

Model 1 packs true sizes; Model 2 packs reported sizes without checking true sizes. Compare their bin counts across paired trials.

6

After placement, a shortfall occurs if perceived need z exceeds assigned resource r. Update q = failed Simple / observed Simple, including successful Simple jobs; Hard leaves q unchanged. Add α = c·max(z − r, 0) to the bin count. c weights this penalty only. Feedback off means no update, q = 0 and α = 0.
