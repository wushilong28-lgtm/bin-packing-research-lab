EXPERIMENT SETUP / 03

Design your experiment

Jobs arrive and depart. Change size and duration reporting, then compare paper-inspired placement rules on the same jobs.

01 Sampling

True size a ~ Uniform(0, 1). Time unit: hours.

02 Arrival & true duration

The first job arrives at 0. True duration D ~ Uniform(min, max); random arrival gaps are exponential with the chosen mean.

03 Mode selection probability

Estimate size z and duration D̃ first. Hard probability is (1 − λ)gₛ(z) + λgₜ(D̃).

z = clip(a + size error, 0, 1). The expression accepts z, exp, log, sqrt, abs, min, max, clamp, step, and arithmetic.

gₜ(D̃) = 1 / (1 + exp(−(D̃ − midpoint) / width)). At the midpoint, duration alone gives 50%.

04 Reported size & duration

After one mode draw, apply the mode bounds to both estimated values.

EXPERIMENT RULES

How this experiment works

1

Draw arrival, true size and true duration. Estimate size with the chosen error and duration with a uniform percentage error.

2

Average size and duration Hard probabilities using λ. Draw one mode, then cap or floor both reports.

3

At each time, departures release reported capacity before simultaneous arrivals. Reported duration controls departure; true values never change occupancy.

4

Threshold algorithms use G + τ. A reported size above that limit gets a singleton bin. Empty bins close; jobs never move.

5

Non-clairvoyant algorithms cannot inspect duration during placement. Clairvoyant algorithms may inspect the reported departure time.
